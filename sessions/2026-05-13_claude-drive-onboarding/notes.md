# Claude + Drive onboarding

## What happened

This session was a practical onboarding session for using Claude with personal finance and document workflows. The attendee was starting from a mostly browser-based Claude setup and an older Mac, so the first part of the session focused on environment constraints: desktop app compatibility, macOS version, browser use, and whether Claude's Google integrations require a paid subscription.

The useful turn was moving from "install an app" to "use Claude in the browser, create a project, and add files intentionally." Kenny walked through how to use Claude projects, when to attach files to the project rather than a single chat, and how to think about model choices such as Opus, Sonnet, and Haiku.

The concrete use case was finance organization. The attendee wanted to keep working in YNAB and bring finance documents/spreadsheets into Claude so it could answer questions and help organize next steps. Kenny recommended starting with exported spreadsheet or CSV-style documents and using Claude projects as the stable workspace.

## Recommendations and demonstrations

- Use Chrome and Claude in the browser if the desktop app cannot run on the current macOS version.
- A paid Claude subscription may be necessary for Google Drive-style integrations.
- Put persistent source files into the Claude project, not only into an individual chat.
- Use Opus for harder advice or reasoning questions, Sonnet for most practical file work, and treat Haiku as less useful for this workflow.
- Start with finance files and ask grounded questions before trying to automate everything.
