# Vetted Asset Inventory

This inventory reconciles the three research passes. It separates usable-now assets from material that needs verification or should stay out of the channel.

## Use Now

### Brand

- Bench & Beacon telescope-wrench mark.
- Navy, cream, and gold Atlas Meridia palette.
- Cormorant Garamond for display.
- Lora for body.
- DM Sans for labels and UI-like text.
- IBM Plex Mono for code or system details.

Use the mark as a small channel signal: avatar, lower-third bug, end card, and thumbnail corner. Do not make the logo do all the brand work.

### Visual Style

- Dark navy background.
- Cream headline type.
- Gold rule, bracket, underline, or tiny accent.
- Clean diagram or screen-grab as the main informational image.
- Real face or real footage when the topic benefits from human presence.

Preferred thumbnail direction:

- 2 to 4 words of large serif text.
- One clear claim.
- No clutter.
- Keep bottom-right clear for YouTube UI overlays.

### Capture And Editing

Use whichever capture path is ready fastest:

- iA Presenter or Keynote for deck recording.
- QuickTime or OBS for screen capture.
- Final Cut Pro or DaVinci Resolve for editing.
- Local Whisper or YouTube captions for caption workflow.
- ffmpeg for compression or repeatable export checks.

### Content Source Material

- `landmarks.md` for the live projects roadmap.
- `offer/offerings.md` for the current offer frame.
- Session notes for concrete examples.
- Walk-talk summaries for thesis formation, after public-safety review.

## Verify Before Scheduling

- Exact YouTube Studio state: channel exists, handle set, verification, custom thumbnails, links, feature eligibility.
- Which domain appears in lower thirds, cards, and descriptions.
- iA Presenter install and export quality.
- Physical availability and clean setup for mic, light, camera, and screen capture.
- Whether OBS is installed and worth using for composited captures.
- Whether Buffer is already connected to the exact YouTube channel.

## Use Selectively

### Personal Footage

Real walking footage, desk footage, Fuji stills, and ordinary screen recordings are useful because they support the channel's lived-practice claim.

Use them when they clarify the idea. Do not spend the pilot rummaging through large media libraries.

### Generated Visuals

Generated backgrounds, textures, or abstract transitions can help as small production elements. They should never become the identity of the channel.

Good use cases:

- subtle title-card texture;
- background layer behind a diagram;
- one-off explanatory insert;
- visual punctuation between sections.

## Avoid For Channel Identity

- AI headshots as the main avatar or public face.
- Robotica, Sable, Elle, Nadine character libraries.
- Generic stock photography.
- Busy AI-tool collage thumbnails.
- Heavy motion templates before the core visual package is stable.
- Any private attendee details, raw transcripts, raw chat logs, emails, phone numbers, or unreviewed client/company context.
